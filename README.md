# Structures-27

Structural analysis and sizing tools for the TR-27 aero package.

| Folder | Contents |
|---|---|
| `wing_structures/` | Rib-and-spar sizing for front and rear wing main elements: section properties, coupled skin/spar beam model, strength and buckling checks. See its README. |

Code is MATLAB and also runs in GNU Octave. Each tool has a `tests/` folder;
run the tests before trusting results after any change.
